# GitHub Copilot App Mini-Hack (5 Challenges)

## Objective
Highlight how to use the **GitHub Copilot App** for planning, building, parallel execution, and review workflows.

---

## Challenge 1
- **Title:** Start in the Copilot App Workspace
- **Challenge Description:** Open the GitHub Copilot App and initialize a focused working session for a repository task.
- **Challenge Scenario:** You just received a feature request. Use the app to open the target repo, describe the task in natural language, and create a clear task goal and acceptance criteria in chat.
- **Suggested Time to Solve:** 15 minutes
- **Resources:**
  - https://github-samples.github.io/copilot-workshops/app/
  - https://docs.github.com/en/copilot/how-tos/github-copilot-app/agent-sessions

## Challenge 2
- **Title:** Build a Task Plan with Copilot
- **Challenge Description:** Use Copilot App to transform a rough request into a structured implementation plan.
- **Challenge Scenario:** A stakeholder asks for “add input validation and better errors.” Ask Copilot to break this into ordered steps, affected files, and validation strategy before coding.
- **Suggested Time to Solve:** 20 minutes
- **Resources:**
  - https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/research-plan-iterate
  - https://docs.github.com/en/copilot/concepts/agents/github-copilot-app

## Challenge 3
- **Title:** Run Parallel Agent Sessions
- **Challenge Description:** Execute multiple independent tasks at once using parallel Copilot App sessions.
- **Challenge Scenario:** Split work into three tracks: test fix, docs update, and refactor suggestion. Run them in parallel sessions, then compare outputs and decide which changes to keep.
- **Suggested Time to Solve:** 30 minutes
- **Resources:**
  - https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/manage-and-track-agents
  - https://github.blog/changelog/2026-06-26-github-desktop-3-6-worktrees-and-deeper-copilot-integration/

## Challenge 4
- **Title:** Review and Improve Copilot Output
- **Challenge Description:** Evaluate Copilot-generated changes for correctness, security, and maintainability.
- **Challenge Scenario:** Copilot proposes a patch for a bug. Review the diff, ask follow-up questions to improve edge-case handling, and request a safer revision.
- **Suggested Time to Solve:** 30 minutes
- **Resources:**
  - https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/review-copilot-output
  - https://docs.github.com/en/copilot/responsible-use/copilot-code-completion

## Challenge 5
- **Title:** Finalize with Pull Request Readiness
- **Challenge Description:** Use Copilot App to prepare a final PR package with summary, risk notes, and validation checklist.
- **Challenge Scenario:** Consolidate accepted outputs from earlier challenges into one branch. Use Copilot to draft a PR description with what changed, why, testing evidence, and rollout considerations.
- **Suggested Time to Solve:** 20 minutes
- **Resources:**
  - https://docs.github.com/en/pull-requests/collaborating-with-pull-requests
  - https://docs.github.com/en/copilot/how-tos/github-copilot-app/agent-sessions
