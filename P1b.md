# GitHub Copilot App Mini-Hack

## Overview
This mini-hack is designed to help participants discover and use the GitHub Copilot App through hands-on challenges. Participants will explore Dashboard, Canvas, Parallel Agent Sessions, Isolated Git Worktrees, Automations, and Rubber Duck Agent capabilities while solving realistic developer and architect scenarios.

**Target Audience:** Developers, Solution Architects, Technical Leads

**Recommended Duration:** 2.0 hours

---

# Challenge 1 – Build Your AI Command Center

## Title
GitHub Copilot App Dashboard Mastery

## Challenge Description
Explore the GitHub Copilot App Dashboard and configure a personalized workspace that helps you track ongoing work, conversations, and coding activities.

## Challenge Scenario
You have just joined a modernization project with multiple workstreams. Create a dashboard view that helps you organize and monitor your development activities and AI-assisted tasks.

## Suggested Time to Solve
20 minutes

## Resources
- https://learn.microsoft.com/en-us/training/paths/copilot/
- https://learn.microsoft.com/en-us/shows/github-copilot-bootcamp/

# Challenge 2 – Design with Canvas

## Title

## Challenge Description

# Challenge 3 – Scale Work with Parallel Agent Sessions

## Title
Conquer Multiple Tasks Simultaneously

## Challenge Description
Launch Parallel Agent Sessions to work on several tasks at the same time.

## Challenge Scenario
Your team must prepare documentation, generate sample code, and create a testing strategy before the end of the day. Use separate agent sessions to complete the work in parallel and consolidate the outputs.

25 minutes

# Challenge 5 – Autonomous Engineering Assistant

## Title
Automations + Rubber Duck Agent Challenge

## Challenge Description
Combine Automations and the Rubber Duck Agent to improve productivity and software quality.

## Challenge Scenario
You inherit an unfamiliar application with limited documentation. Use the Rubber Duck Agent to explain the codebase and identify improvement opportunities. Then create Automations that summarize findings, generate follow-up tasks, and produce recurring status updates.
